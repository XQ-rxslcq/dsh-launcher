# 素材说明（本仓库不含图片素材）

**本仓库不包含任何角色图片素材。** 桌面图标与加载动画表情需要由使用者自行准备，并在设置页「启动器设置」中通过 `iconPath` / `stickerDir` 绑定本地图片。

## 为什么不含素材

启动器最初使用的「女仆鲸鱼娘 / DeepSeek娘」表情与图标，其来源仓库（YunYueSama/codex-deepseek-pet 等）明确声明：

> assets/ 中的角色原始图片……不授予复制、重新分发、出售、再许可或制作图片衍生作品的额外权利。

为彻底避免版权争议，本仓库已移除所有图片，改为**纯代码分发**。请勿将任何未获授权的角色图片提交回本仓库。

## 如何绑定你自己的素材

1. 准备一个图标文件（png / ico）与若干张表情图（透明背景 png / webp / jpg，会按文件名排序循环播放）。
2. 打开 DSH 设置页 →「启动器设置」：
   - **图标路径**：填图标文件路径，或点「选择…」选图标所在目录。
   - **表情目录**：填表情所在目录，或点「选择…」选择。
3. 保存后，用 `/launcher` 唤起启动器，即可显示你自己的素材。
